# 安装成应用

## Mac 本地工作台

双击 `Agent Office.app` 会启动本地办公室并在独立窗口中打开工作台。「选择项目」使用 Finder 的文件夹选择器。办公室服务在 App 之外单独运行，本机模型也加载在里面：

- **退出 App（⌘Q 或关闭窗口）**：如果没有任务在执行，办公室和本机模型会一起停止，释放内存；如果还有任务在执行，会询问你「后台继续并退出」还是「停止并退出」。选择后台继续时，下次打开 App 可以直接看到结果。
- **随时停止**：菜单栏「Agent Office → 停止办公室服务…」。停止后点窗口里的「重试」即可重新启动。

在装有 Xcode 命令行工具、Python 3 和 Node.js 22.19 或更新版本的 Mac 上，可以从项目根目录打包和验证：

```sh
npm ci
python3 macos/build.py --project . --output "release/Agent Office.app"
node macos/smoke.mjs "release/Agent Office.app"
```

`--project .` 将当前办公室目录记录在本机应用中，运行时沿用这里的 `.env.local`、Pi 和办公室数据。分发给其他人时可省略 `--project`，应用会在 `~/Library/Application Support/Agent Office` 中读取配置并保存数据。生成的应用使用本机架构和本机签名，运行时需要 Node.js。

如果原办公室放在「文稿」里，macOS 首次打开或更新后可能询问是否允许 Agent Office 访问「文稿」。同意后即可继续使用原有数据。如果授权时窗口已经显示「连接超时」，点「重试」即可。

更新时，选用新的输出路径。等旧版任务完成后，在旧版里选「Agent Office → 停止办公室服务…」或直接退出，再双击新版本。工作台会核对服务版本与数据目录。

## 浏览器安装版（PWA）

Agent Office 可以像应用一样安装（PWA）：出现在主屏幕、程序坞或开始菜单，在独立窗口里打开，没有浏览器地址栏。它打开的仍是你的办公室网站，登录状态、权限和数据都与网页版相同。

本地版启动后，可以在 Mac 的 Safari 中打开 <http://127.0.0.1:3080/>，用「文件」→「添加到程序坞」做成独立窗口。应用窗口打开的是本机服务，所以使用前要先双击启动器（或运行 `npm start`）。本地版不注册离线缓存，下面的离线说明只适用于网站版；Chrome / Edge 是否在本地地址上显示安装按钮，取决于浏览器版本。

## 怎么安装

先在浏览器里打开办公室并完成站点登录，然后：

| 设备 | 操作 |
| --- | --- |
| iPhone / iPad（Safari） | 点底部「分享」→「添加到主屏幕」 |
| Mac（Safari 17 及以上） | 菜单栏「文件」→「添加到程序坞」 |
| Mac / Windows（Chrome、Edge） | 点工作台右上角「安装应用」，或地址栏右侧的安装图标 |
| Android（Chrome） | 点「安装应用」，或菜单里的「安装应用 / 添加到主屏幕」 |

工作台右上角的「安装应用」按钮：在 Chrome / Edge 中直接弹出安装确认；在 Safari 中打开上面的步骤说明。已经以应用方式打开时，这个按钮不会出现。

安装后可以在图标上长按（手机）或右键（电脑）使用两个快捷入口：「完整办公室」和「体验演示」。

## 离线与更新

- 打开过的页面在断网时仍能打开，没打开过的页面显示「暂时连不上办公室」，点「重新连接」即可。
- 聊天、成果、任务等数据始终直接请求服务器，从不使用缓存，所以不会看到过期内容；断网期间发送的消息会标记为「发送未确认」，可以在恢复后重试。
- 发布新版本后，应用会在下次打开时自动换成新版本，无需重新安装。
- 页面每次都会先向服务器确认，因此登录过期时会正常跳转到登录页。

## 卸载

- 手机：长按图标 →「删除 App / 卸载」。
- Mac 程序坞：右键图标 →「选项」→「从程序坞中移除」，或在「应用程序」文件夹里删除；Chrome / Edge 安装的应用在 `chrome://apps` 或 `edge://apps` 中卸载。

## PWA 的运行方式

- 应用需要网络才能与伙伴协作；它不会在后台运行 Agent，也不会推送系统通知。
- Agent 仍由你自己的运行环境通过 MCP 接入，安装应用不会启动模型。

## 维护者说明

| 文件 | 作用 |
| --- | --- |
| `public/manifest.webmanifest` | 名称、颜色、图标与快捷入口 |
| `public/icons/*.svg` | 图标源文件；改动后在 macOS 上运行 `npm run icons` 重新生成 PNG |
| `public/offline.html` | 离线提示页 |
| `scripts/service-worker.js` | Service Worker 模板；`npm run build` 写入版本号和预缓存列表，发布为 `/sw.js` |

开发服务器（`npm run dev`）不注册 Service Worker，避免本地调试时读到旧缓存。要验证应用行为，请用 `npm run build && npm run preview`，打开 <http://127.0.0.1:3090/>。
