    把 Agent Office 装成应用
    安装后它会出现在主屏幕、程序坞或开始菜单，在独立窗口里打开，登录状态和数据与网页版相同。
    1. iPhone / iPad（Safari）：点底部「分享」，选「添加到主屏幕」。
    2. Mac（Safari）：菜单栏「文件」→「添加到程序坞」。
    3. Chrome / Edge：地址栏右侧的安装图标，或菜单里的「安装 Agent Office」。
    4. Android（Chrome）：菜单里的「安装应用」或「添加到主屏幕」。
    应用仍然连接你的办公室网站。断网时会显示离线提示，恢复网络后继续同步。
